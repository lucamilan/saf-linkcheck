# 001 · Cool URIs don't change (W3C, 1998)

- **Status:** distilled
- **Date:** 2026-08-09
- **Provenance:** https://www.w3.org/Provider/Style/URI - Tim Berners-Lee, W3C Style

W3C note on the decay of URIs: addresses stop working because people reorganize content, not because technology forces it; a good URI is designed not to change. Registered because it touches linkcheck's scope: checking external links fights a structural phenomenon (link rot), not an occasional accident.

# Sources — raw external knowledge

Intake of **external material** (articles, papers, transcripts, docs, URLs) from which
internal cognition is distilled. It is NOT the distillate: that lives in `.knowledge/`
or `.decisions/`, linked back to the source.

Content policy: raw material inline **if short**, otherwise a pointer — no heavy files
inside `.saf/`.

Form, fields and commands: `saf-tools describe --type source`.
